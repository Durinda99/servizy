# Сервизы — учёт клиентов, собирающих сервиз по частям

Приложение для телефона (PWA): работает без интернета, данные хранятся только в телефоне (IndexedDB).
Сделано по документам «ТЗ: учёт клиентов, собирающих сервизы по частям», «Схема базы данных: сервизы по частям» (v2) и эскизам «Эскизы приложения: сбор сервизов».

## Состав

```
(корень репозитория)     ← это и есть сайт; GitHub Pages публикует его целиком
index.html
manifest.webmanifest  иконка и название на главном экране
sw.js                 кэш для работы без интернета (VERSION — номер выпуска)
css/app.css
js/
    app.js              запуск, маршруты экранов
    db.js               таблицы схемы v2, запись в IndexedDB, резервная копия
    model.js            цены, состав, подбор клиентов по товару, запросы, покупки, напоминания
    importer.js         загрузка каталога из Excel-файла с сайта (ТЗ 4.8)
    xlsx.js             чтение и запись .xlsx без сторонних библиотек
    ui.js, util.js      общие элементы интерфейса и помощники
    screens-*.js        экраны
data/
    seed.json           стартовый каталог на 05.11.2026 (1977 товаров, 860 комплектов; с разделом «Фарфоровые чашки»)
    kindmap.json        соответствие видов изделий (из «Соответствие_видов.xlsx»)
icons/
tools/build-seed.mjs    пересборка data/*.json из файлов Excel (Node 18+)
```

Сторонних библиотек нет, сборка не нужна.

## Как поставить на телефон

1. Сайт публикуется GitHub Pages из корня ветки main: https://durinda99.github.io/servizy/ . Можно выложить и на любой другой хостинг с https (например, GitHub Pages).
2. Открыть адрес в Chrome на телефоне → меню ⋮ → «Добавить на главный экран» (или «Установить приложение»).
3. При первом запуске нажать «Загрузить каталог на 05.11.2026». Дальше интернет не нужен.

## Выпуск обновления

Изменить файлы, увеличить `VERSION` в `sw.js` и выложить. Телефон подхватит новую версию при следующем открытии с интернетом. Данные клиентов при обновлении не трогаются.

## Пересборка стартового каталога

```
node tools/build-seed.mjs путь/к/ipm_stolovye_chayno-kofeynye_servizy.xlsx [путь/к/Соответствие_видов.xlsx] [ГГГГ-ММ-ДД]
```

Файл соответствия видов необязателен: без него берётся текущий `data/kindmap.json`, а новым товарам вид подбирается по правилам. Дата — с какого дня действуют цены из файла (по умолчанию сегодня). После пересборки поменяйте дату и числа на кнопке первого запуска (`js/screens-more.js`) и `VERSION` в `sw.js`.

Три крышки заварочных чайников (80.04229.00.1, 80.97404.00.1, 80.56214.00.1) при сборке переводятся в вид «Крышка».

## Проверка на компьютере

```
python3 -m http.server 8765
```
и открыть http://localhost:8765 (лучше в режиме эмуляции телефона в Chrome).

## Что не входит в первую версию

Уведомления на телефон о напоминаниях (вторая версия), складской учёт, бронирование, синхронизация между устройствами.
