# Обновление каталога ipm.ru для приложения «Сервизы»

Инструкция, чтобы повторить выгрузку каталога с сайта Императорского фарфорового завода и обновить приложение без старого чата. Её можно выполнить самому по шагам ниже или дать новому чату с Claude и написать: «Обнови каталог ipm.ru по инструкции в tools/catalog/README.md».

## Файлы комплекта

| Файл | Что делает |
|---|---|
| `README.md` | этот документ |
| `ipm_scrape.js` | сбор каталога в браузере → файл `ipm_all.json` |
| `ipm_build_xlsx.py` | `ipm_all.json` → Excel с превью фото (листы «Товары» и «Состав комплектов») |

Приложение лежит в репозитории GitHub **Durinda99/servizy**. Его адрес: https://durinda99.github.io/servizy/. Встроенный каталог хранится в `data/catalog.json`, а собирается командой `tools/build-seed.mjs`.

## Что собирается

Собираются четыре раздела сайта. Всего около 1 980 товаров по состоянию на ноябрь 2026.

| Адрес | В колонке «Раздел» |
|---|---|
| /catalog/stolovye-predmety/ | Столовые предметы |
| /catalog/chayno-kofeynye_predmety/ | Чайно-кофейные предметы |
| /catalog/chashki_s_blyudtsami/ | Чайно-кофейные предметы |
| /catalog/servizy/ | Сервизы |

«Фарфоровые чашки» (`/catalog/chashki_s_blyudtsami/`) — отдельный раздел сайта. В меню он стоит внутри «Чайно-кофейных предметов», но его товары не выводятся на страницах этого раздела. Если его пропустить, потеряется около 760 чашек. Список разделов задаётся в начале `ipm_scrape.js` (массив `SECTIONS`).

## Колонки Excel (лист «Товары»)

№, Фото (превью внутри файла), Название, Раздел, Подраздел, Форма, Рисунок, Персон, Предметов, Состав комплекта (артикул — предмет — шт.), Материал, Вид изделия, Коллекция, Вес г, Год начала выпуска, Артикул, Цена руб., Наличие, Фото в галерее шт., Ссылка на товар, Ссылка на фото.

На листе «Состав комплектов» каждая строка — один предмет: артикул комплекта, название комплекта, артикул предмета, предмет, шт., высота, длина, ширина, объём, вес.

Откуда берутся данные:
- **Список товаров** (название, артикул, цена, наличие, ссылка) — из блока JSON-LD `<script type="application/ld+json">` на каждой странице списка `?PAGEN_1=1, 2, 3…`. По 27 товаров на странице.
- **Характеристики** — из таблицы `.char_block` на карточке товара.
- **Состав комплекта** — из таблицы `.complectTable` на карточке товара.
- **Раздел и подраздел** — из хлебных крошек `.breadcrumbs`.
- **Фото** — первое фото галереи `.item_slider .slides a.popup_link`. Сайт отдаёт его в AVIF, который Excel не показывает. Оригинал в JPG лежит по тому же пути без `/resize_cache/avif`:
  `cdn.ipm.ru/upload/resize_cache/avif/upload/iblock/17b/x.avif` → `cdn.ipm.ru/upload/iblock/17b/x.jpg`
- **Форма, рисунок, персоны, предметы** — из названия («…форма Весенняя 2 рисунок Сад мечты, 6 персон 20 предметов…»). Если в названии их нет — из характеристик.
- **Товар из нескольких разделов** записывается одной строкой, разделы перечисляются через запятую.

## Порядок действий

### Шаг 1. Собрать данные (15–25 минут)
1. Откройте в Chrome https://www.ipm.ru/catalog/. Если появится капча, пройдите её.
2. Нажмите F12 и откройте вкладку **Console**.
3. Вставьте всё содержимое `ipm_scrape.js` и нажмите Enter. Если Chrome не даёт вставить, наберите `allow pasting`, нажмите Enter и вставьте снова.
4. Дождитесь сообщения `ГОТОВО`. Браузер скачает `ipm_all.json` (10–25 МБ) в «Загрузки».

Если в консоли появилось «САЙТ ПОКАЗАЛ КАПЧУ»: обновите страницу, пройдите капчу, подождите 10–30 минут и запустите сбор снова. Капча появляется от слишком частых запросов. Если она повторяется, уменьшите в начале файла `THREADS` до 2 и увеличьте `PAUSE_MS` до 400.

### Шаг 2. Собрать Excel (1–2 минуты)
Нужен Python 3 и библиотеки: `pip install openpyxl pillow`.
```
python3 ipm_build_xlsx.py ipm_all.json ipm_catalog.xlsx
```
Скрипт напишет, сколько собрано товаров, строк состава и превью. Сверьте с прошлым разом: резкое падение означает, что сбор прервался или сайт изменил вёрстку.

### Шаг 3. Обновить приложение

**Вариант А. Загрузить Excel прямо на телефон** (быстро, ничего не публикуется).
Перекиньте `ipm_catalog.xlsx` на телефон. В приложении откройте **«Ещё» → «Загрузить файл с сайта (Excel)»**, выберите файл и укажите дату цен. Товары сопоставляются по артикулу: новые добавляются, у старых обновляются поля, изменённые цены попадают в историю. Ничего не удаляется. Клиенты, запросы и напоминания не трогаются.

**Вариант Б. Обновить встроенный каталог** (чтобы новые установки сразу получали полный справочник, а на старых телефонах появлялась кнопка «Обновить до встроенного каталога»).
Нужны Node.js 18+ и git. Команды выполняются в корне репозитория.
```
git clone https://github.com/Durinda99/servizy   # если репозитория ещё нет
cd servizy
node tools/build-seed.mjs путь/к/ipm_catalog.xlsx 2026-12-01      # дата, с которой действуют цены
```
Затем вручную:
1. В `js/screens-more.js` поправьте константу `BUILTIN = { date, products, bundles }`. Числа скрипт печатает в конце (`products sold separately` и `bundles`).
2. В `sw.js` увеличьте `VERSION`, например `servizy-1.2.0` → `servizy-1.3.0`. Без этого телефоны не получат обновление.
3. Поправьте даты и числа в основном `README.md`.
4. Проверьте на компьютере: `python3 -m http.server 8765`, откройте http://localhost:8765 в режиме телефона, нажмите «Загрузить каталог» и найдите пару новых товаров.
5. Отправьте изменения: `git add -A && git commit -m "Каталог на <дата>" && git push`. GitHub Pages опубликует их за 1–2 минуты.

Встроенный каталог (`data/catalog.json`) сам по себе на телефон, где уже есть данные, не попадает. Там его принимают кнопкой «Обновить до встроенного каталога» в разделе «Ещё».

## Как это делать через Claude

Дайте Claude доступ к репозиторию (или эти три файла) и напишите: «Обнови каталог ipm.ru по инструкции в tools/catalog/». Что ему понадобится:
- **Встроенный браузер приложения Claude на компьютере.** Прямой доступ к ipm.ru и cdn.ipm.ru из среды Claude закрыт, поэтому сбор идёт в браузере на вашем компьютере. Claude запускает `ipm_scrape.js` через выполнение JavaScript на открытой странице ipm.ru, проверяет прогресс через `window._ipmJob` и забирает готовый `ipm_all.json`.
- **Доступ к папке «Загрузки».** Туда браузер сохраняет `ipm_all.json`. Иногда файл сначала появляется с именем вида `xxxxxxxx-….tmp` того же размера и через пару секунд переименовывается. Excel Claude собирает у себя через `ipm_build_xlsx.py`.
- **Капча.** Проходить её может только человек. Claude попросит открыть встроенный браузер (Ctrl+Shift+B) и пройти её.
- **Отправка на GitHub.** Для шага 3б Claude нужен доступ на запись к репозиторию Durinda99/servizy. Его дают через подключение GitHub в Claude.

## Известные особенности сайта
- Несколько товаров есть в списке, но их страница отдаёт 404: товар снят. Они попадают в файл только с данными из списка (название, артикул, цена, ссылка).
- У части карточек нет характеристик, состава или года выпуска. Соответствующие ячейки остаются пустыми, это нормально.
- В составе некоторых наборов сайт даёт ошибочные размеры (например, у чайника высота 16 мм). Они переносятся как есть.
- Сайт иногда меняет порядок товаров между страницами списка. Если товаров стало заметно меньше обычного, запустите сбор ещё раз.
- Если сайт сменит вёрстку, сломаются селекторы в `ipm_scrape.js`: `.char_block`, `.complectTable`, `.item_slider .slides a.popup_link`, `.breadcrumbs [itemprop="name"]`. Их нужно будет поправить под новую страницу.
